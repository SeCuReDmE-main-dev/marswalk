# Google Antigravity Configuration (`.antigravity/README.md`)

This directory configures **Google Antigravity** agents operating on the `marswalk` repository:

- **`rules/workspace-governance.md`:** Folder isolation on `main` (`frontend/` vs engine folders), provenance tag rules (`MEASURED | DERIVED | SIMULATED`), and zero-stub enforcement.
- **`workflows/verify-pack.md`:** Step-by-step workflow to rebuild and validate the `public_packs/jezero/v1/` static pack.
