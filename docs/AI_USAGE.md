# Transparent AI & Tool Usage Disclosure (`docs/AI_USAGE.md`)

In full compliance with the **2026 NASA International Space Apps Challenge** rules on transparency and attribution, this document discloses how Artificial Intelligence assistants were used during the development of **MarsWalk**.

---

## 1. Summary of AI Assistance

| Tool / Model | Role in Workflow | Human Verification Gate |
| :--- | :--- | :--- |
| **Claude Code (Anthropic)** | Scientific literature synthesis, verification of NASA Mars 2020 `M20_waypoints.json` schema (`708` Perseverance stops), Mars Trek WMTS projection check (`geographic_2to1_256px`), and contract specification review. | All URLs, HTTP 200/206 headers, and coordinate bounds were verified against live NASA/USGS endpoints and tested via `pytest`. |
| **Google Antigravity IDE (Gemini)** | Repository scaffolding, Pydantic v2 contract modeling (`src/marswalk/contracts/`), deterministic pack builder (`src/marswalk/middleware/`), FastAPI endpoints, and automated test suite (`tests/`). | Every generated module is validated by `ruff check .`, `ruff format --check .`, JSON Schema Draft 2020-12 export checks, and a 500-request concurrency stress test. |
| **OpenAI Codex (Optional Teammate Bridge)** | Optional frontend code assistance and workspace bridging on the frontend worktree. | Reviewed and integrated by the human Frontend Lead (`@Maptop`). |

---

## 2. What Was NOT Generated by AI

1. **Planetary Telemetry & Waypoints (`MEASURED`):** The `708` Perseverance rover waypoints (`Sol 13 → Sol 2022`), rover tilt measurements (`rover_tilt_deg`, `rover_pitch_deg`, `rover_roll_deg`), elevations (`elev_geoid_m`), and ground panorama links come directly from NASA/JPL Mars 2020 MMGIS (`M20_waypoints.json` and `M20_traverse.json`).
2. **Engineering Safety Thresholds (`MEASURED`):** Suit slope limits (`20°`), walkback distance (`2.0 km`), rover bedrock/sand slope limits (`20° / 10°`), rock abundance CFA thresholds (`7% / 15%`), and Curiosity RAD surface GCR radiation (`0.67 mSv/day`) are sourced directly from published NASA xEVA, JPL Robotics, and SwRI MSL documents cited in `manifest.json`.
3. **Basemap Imagery:** HiRISE `25 cm/px` orthomosaic tiles are streamed directly from NASA Solar System Treks (`trek.nasa.gov`).
